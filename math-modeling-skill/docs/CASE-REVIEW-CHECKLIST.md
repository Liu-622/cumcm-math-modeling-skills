# 案例卡审查清单

## 身份与来源

- [ ] `case_id`、`paper_id`、年份、题号和标题一致且唯一；
- [ ] `source_page` 可访问并指向对应官方展示页；
- [ ] `evidence_mode` 与实际提取方式一致；
- [ ] 证据锚点包含页码、明示/推断和置信度；
- [ ] 没有上传原论文、截图、附件或 OCR 缓存。

## 建模决策

- [ ] 核心矛盾和数据结构描述准确；
- [ ] 子问题依赖与误差传播已说明；
- [ ] 模型选择理由与数据、目标、约束相对应；
- [ ] 论文实际模型与专家建议替代方案明确分开；
- [ ] 公式和算法描述具有现实含义；
- [ ] 验证方法没有被夸大；
- [ ] 定量结果有来源并注明适用边界。

## 迁移与表达

- [ ] 可迁移经验是决策规则，而不是题目答案；
- [ ] 明确哪些内容不能机械复制；
- [ ] 没有大段近似原文或摘要式复述；
- [ ] 语言为独立、结构化、批判性表达；
- [ ] 没有把模型出现频次当作优越性证据；
- [ ] 没有获奖承诺、官方背书或未经证实的因果结论。

## 索引与自动检查

- [ ] 已运行 `build_case_index.py`；
- [ ] 三种索引只出现预期变化；
- [ ] `validate_skill_content.py` 通过；
- [ ] `validate_repository.py` 通过；
- [ ] 案例检索能够命中新卡且排序合理。
