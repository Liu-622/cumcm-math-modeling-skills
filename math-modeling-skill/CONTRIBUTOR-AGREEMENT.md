# 贡献授权约定

本约定适用于向 `skillforCUMCM/math-modeling-skill-pro` 提交的 Issue 附件、Commit、Pull Request、代码、案例卡、知识文档、模板、测试和其他可合并内容。

提交 Pull Request 即表示贡献者确认：

1. 本人有权提交该贡献，且贡献不违反与雇主、学校、团队、赛事、客户或其他主体的协议；
2. 贡献为本人原创，或本人已明确标注第三方部分并取得提交所需的权利；
3. 未提交原论文 PDF、页面图片、附件、OCR 缓存、大段近似原文、密钥、私人数据或其他无权公开给项目维护者的材料；
4. 对论文方法、结果或公式的描述已经提供可核验来源，并区分原论文明确做法与贡献者自己的建议；
5. 授予 `skillforCUMCM` 一项永久、全球、非独占、免版税、不可撤销的许可，使其可以为本项目复制、使用、修改、组合、展示、分发、再许可并商业化该贡献；
6. 同意项目维护者可以在 Pro 私有版、公共体验版、文档、发行包和衍生版本中使用或不使用该贡献，并可为质量、格式、版权和产品一致性进行修改；
7. 理解本授权只涉及贡献者有权授权的部分，不转移或扩大任何第三方论文及其他材料的权利；
8. 理解提交贡献不自动形成雇佣、委托、合伙、分成或报酬关系，除非双方另有书面约定。

如果贡献者不能接受或不能作出以上确认，请不要提交 Pull Request；可以先通过 Issue 或 Discussion 只描述建议，由维护者独立实现。

本约定是仓库协作政策，不构成法律意见。涉及重要商业合作、版权转让或大规模公开发行时，项目所有者应另行签署正式协议并进行专业法律审查。
