# 社区行为准则

本项目希望形成严谨、友善、重证据的数学建模协作环境。所有仓库成员在 Issue、Discussion、Pull Request、代码审查和其他项目交流中都应遵守本准则。

## 我们鼓励

- 针对模型假设、数据条件、证据和验证方法讨论，不针对个人；
- 清楚区分事实、论文记录、推断和个人建议；
- 对不同建模路径保持开放，并用可复现实验或反例支持判断；
- 尊重贡献者的时间、署名和专业背景；
- 主动纠正错误、披露不确定性和利益冲突；
- 保护私人仓库内容、个人数据、访问凭据和第三方权利。

## 不可接受

- 人身攻击、歧视、骚扰、威胁或持续性的恶意贬低；
- 伪造来源、实验、结果、身份或贡献记录；
- 抄袭、代写、冒充原创或故意绕过赛事规则；
- 未经授权公开仓库内容、原论文文件、私人数据或访问凭据；
- 利用审查权限进行报复、利益输送或压制合理的技术异议；
- 在收到停止要求后继续发布无关广告、引战或骚扰内容。

## 处理方式

一般分歧应先在对应 Issue 或 PR 中基于证据解决。涉及骚扰、安全、私人数据或严重利益冲突时，请直接联系组织所有者，不要公开敏感细节。

维护者可以编辑或删除不当内容、锁定讨论、拒绝贡献、限制或撤销仓库权限。处理时应记录事实、保持比例原则，并尽量让受影响者了解决定和后续要求。
