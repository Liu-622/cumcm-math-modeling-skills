## 验证从主张开始

验证不是论文末尾的固定装饰，而是对核心主张的反证尝试。先建立映射：

| 主张 | 需要的证据 | 不足的证据 |
|---|---|---|
| 预测准确 | 未见数据/滚动外测、合理指标、基线 | 训练拟合优度 |
| 排名可靠 | 权重/标准化/样本扰动下排序稳定 | 一组固定权重的排名 |
| 方案最优 | 可行性、最优性界或精确对照 | 元启发式单次最好值 |
| 方案稳健 | 参数/情景/分布扰动仍可行且效用可接受 | 基准情景表现好 |
| 聚类有意义 | 稳定性、内部指标、外部解释 | 仅二维可视化看起来分开 |
| 机制合理 | 量纲、守恒、参数可辨识、残差/现象复现 | 曲线拟合好 |
| 创新有效 | 公平基线、消融、实际增益、代价 | 模型更复杂或更新 |
| 建议可执行 | 现实约束、成本、风险与边界 | 模型输出直接翻译成政策 |

每个验证都预先声明：对象、扰动/切分、指标、阈值、重复次数和失败判据。看到结果后才挑验证方式会高估性能。

## 数据切分与泄漏防护

| 数据结构 | 正确协议 | 常见错误 |
|---|---|---|
| 独立同分布表格 | 训练/验证/测试或嵌套 K 折 | 在测试集选特征/调参 |
| 时间序列 | 扩展窗/滑动窗、严格按时间滚动 | 随机打乱、用未来均值填历史缺失 |
| 同一主体多记录 | GroupKFold/留主体外 | 同一主体同时在训练与测试 |
| 空间数据 | 空间阻断、留区域外、缓冲带 | 随机点切分导致邻近泄漏 |
| 网络边/节点 | 按任务设计时间或结构切分 | 删边后邻接特征仍含测试边 |
| 图像/文档页 | 按原论文/对象分组切分 | 同一对象的相邻页跨集合 |
| 小样本 | 留一/重复 K 折/Bootstrap，控制调参自由度 | 反复试验后报告最好一折 |

预处理器、缺失填补、缩放、PCA、特征筛选、过采样和阈值选择必须只在训练折拟合，并通过流水线应用到验证/测试。

### 嵌套验证

当候选模型、超参数或特征较多时：内层选择，外层估计泛化。最终测试集只使用一次。若竞赛数据不允许独立测试，诚实报告交叉验证不确定性和选择偏差风险。

## 按任务选择验证

### 预测与回归

- 至少一个朴素/线性基线；时间序列用季节朴素或上一期。
- 报 MAE/RMSE/MASE 等互补指标；百分比指标先检查零值。
- 检查残差均值、异方差、自相关、尾部和分组偏差。
- 概率/区间预测同时看覆盖率、宽度、校准，不只看点误差。
- 外推需用情景、机制边界或历史回测限制结论，不能由高 `R²` 自动证明。

### 分类

- 混淆矩阵 + 与任务成本匹配的 Precision、Recall、F1、ROC-AUC/PR-AUC。
- 类别不平衡优先 PR-AUC、少数类召回和成本；准确率不得单独使用。
- 概率用于决策时做校准曲线、Brier/Log loss 和阈值敏感性。
- 检查不同时间、区域、群体的分组性能，识别漂移和不公平。

### 综合评价与排名

- 变更标准化、方向化、权重、距离和阈值，报告名次区间/秩相关。
- 删除一个指标、对相关指标合并/降权，检查重复计权。
- 对权重做单因素、情景或概率扰动；识别排名翻转阈值。
- 有外部结果时做效标效度；无真值时报告稳定性和专家/现实一致性，不伪造“准确率”。
- DEA 检查规模报酬、变量数/样本数、异常决策单元和 Bootstrap 偏差。

### 聚类

- 内部指标：Silhouette、Calinski-Harabasz、Davies-Bouldin，多指标不必一致。
- 稳定性：重采样、不同初始化、距离、特征和 K；用 ARI/NMI/共识矩阵比较。
- 外部解释：簇在未用于聚类的变量、后续任务或现实机制上是否有区分。
- 不能用内部指标“证明”簇是真实类别；若不稳定，应报告连续谱或软归属。

### 优化

1. **可行性**：逐条计算约束余量，检查单位、整数和逻辑约束。
2. **正确性**：小规模枚举/精确求解，与手算边界或松弛界比较。
3. **最优性**：LP/MILP 报对偶/界/gap；非凸或启发式只称“当前最好/近优”，除非有证明。
4. **算法性**：多随机种子、收敛轨迹、运行时间分布、同预算比较。
5. **决策性**：外部/样本外情景中的目标、后悔值、失效率和可执行性。
6. **多目标**：前沿收敛、分布、HV/IGD 或 ε-constraint 对照；偏好变化下推荐解是否稳定。

### 图与网络

- 人工小图核对路径、流、连通和边界条件。
- 改变边阈值、权重、缺边/增边，检查中心性、社区和路径稳定。
- 负权、非对称、时变或容量必须用匹配算法并构造边界测试。
- 网络指标与现实结果的关系需要外部证据；中心性本身不证明因果影响。

### 机理/微分方程

- 量纲一致、守恒/非负/边界、极限情况和稳态检查。
- 参数可辨识性：Profile likelihood、Fisher 信息、后验相关或多初值拟合。
- 数值验证：步长/网格收敛、不同求解器、容差敏感。
- 经验验证：残差结构、留出期/实验、关键现象和临界点。
- 若多个参数组合均可解释数据，报告等效区间，不给虚假精确值。

### 仿真

- **验证 verification**：程序是否按规则运行，做单元测试、守恒和极端输入。
- **确认 validation**：输出是否再现现实统计、分布或定性模式。
- 报暖机期、重复次数、随机种子方案、方差与置信区间。
- 做情景覆盖、参数校准/留出、结构消融；禁止只展示一条轨迹。
- 高风险尾部事件需检查样本量与重要抽样/方差缩减，而非依赖普通 Monte Carlo 的少量样本。

## 敏感性与不确定性

### 区分四类对象

- **数据不确定性**：测量误差、缺失、采样偏差。
- **参数不确定性**：估计误差、专家给定区间。
- **结构不确定性**：候选模型/机制不同。
- **情景不确定性**：未来政策、需求、环境不可概率化。

不得只扰动最容易处理的参数，却忽略主导的结构或数据不确定性。

### 局部敏感性

适用于平滑模型和基准点附近。可计算弹性：

\[
S_{y,x}=\frac{\partial y}{\partial x}\frac{x}{y}.
\]

用 ±5%、±10% 只是示例，扰动范围应来自测量误差、置信区间、历史波动或合理情景。

### 全局敏感性

当非线性、交互或大范围不确定性重要时，使用 Morris、Sobol、拉丁超立方/Monte Carlo、部分秩相关等。报告参数分布来源和交互贡献。

### 不确定性传播

- 解析/Delta method：近线性、参数分布简单。
- Bootstrap：采样不确定性与复杂统计量。
- Monte Carlo：任意分布和非线性链。
- Bayesian posterior predictive：参数与预测联合不确定性。
- 情景集/区间：无法可信指定概率时。

上游输出进入优化/评价时，保留样本、分位数或情景，而不是只传均值。

### 稳健性

稳健性关注结论在合理扰动下是否保持。建议定义：

- 可行率；
- 性能最坏/分位数；
- 排名翻转率；
- 决策后悔值；
- 参数/场景稳定区间；
- 结论不变域。

## 对比、消融与统计判断

### 公平对比

所有模型使用同一训练信息、外测切分、指标、调参预算和计算资源。若预算不同，明确报告，不用不公平基线制造优势。

### 消融

逐一删除新特征、新约束、新损失、新模块或改进算子。对组合链还需端到端消融，详见 `model-combinations.md`。

### 统计与实际显著

- 多折/多时间窗误差可用配对比较、Bootstrap 置信区间或适合依赖结构的检验。
- 多随机种子报告分布，不只报最优。
- `p < 0.05` 不等于实际重要；同时报告效应量、置信区间和业务阈值。
- 样本很小或依赖强时，不强行做不可靠显著性检验，改用区间、情景和限制性表述。

## 误差分析与失败情景

按以下切片定位错误：时间阶段、空间区域、目标量级、类别、群体、边界/极端情景、缺失率、预测距离。对每类回答：

1. 错误是否来自数据质量、结构遗漏、参数估计、数值求解或随机性？
2. 错误是否系统性偏向某个群体/区间？
3. 是否影响核心结论或只影响次要指标？
4. 能否通过更简单的修复解决？
5. 失败时现实决策的后果是什么？

必须主动展示至少一个模型失效或结论反转的情景，给出使用边界。

## 最低验证包

每个子问至少包含：

- 一个匹配任务的基线；
- 一个正确的数据切分/小规模精确检查；
- 一个主要指标和一个互补指标；
- 对关键参数、权重、情景或数据扰动的敏感性；
- 一项误差/失败情景分析；
- 若有创新模块，一项消融；
- 若有随机算法，多随机种子与运行时间；
- 若结果进入后续子问，不确定性传播或稳定性检查。

验证篇幅不足时，优先覆盖核心主张和高风险假设，不机械塞满所有方法。
