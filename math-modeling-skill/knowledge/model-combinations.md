## 组合准入规则

只有同时满足以下条件，才允许增加第二个或后续模型：

1. **独立职责**：新模块解决前一模块没有解决的明确问题，如降维、预测、决策、校准或不确定性传播。
2. **接口清晰**：能写出输入、输出、单位、维数、时间边界和误差含义。
3. **增益可测**：可通过消融、对照或约束可行性证明其贡献。
4. **错误可传播**：上游误差不会被当成无误差真值，或已通过情景/区间传给下游。
5. **总链可解释**：组合后的现实问题 → 数学抽象 → 求解 → 验证 → 结论仍能一口气讲清。

如果只能说“模型 X 很先进”，但说不出它修复了哪个可观察缺陷，则删除该模块。

## 模块契约

每个接口都保存以下契约，防止子问题间语义丢失：

```yaml
producer: "上游模块"
consumer: "下游模块"
artifact: "数组/参数/分布/标签/场景集/图"
shape_and_unit: "维数与量纲"
availability_time: "何时可获得，是否含未来信息"
uncertainty: "标准误/区间/分位数/场景权重"
assumptions: []
validation: "如何证明该接口可信"
fallback: "接口失败时的替代输入"
```

常见模块职责：

| 层 | 典型职责 | 允许的输出 | 不允许的偷换 |
|---|---|---|---|
| 数据 | 清洗、对齐、缺失处理 | 带数据字典的数据集 | 用全数据估计测试期参数 |
| 表示 | 特征、降维、嵌入、指标 | 可解释特征/低维表示 | 把无监督分量直接称现实因子 |
| 推断/预测 | 参数、未来量、类别概率 | 点/区间/分布 | 把拟合值当因果效应 |
| 评价 | 效用、优先级、等级 | 分数/排名及稳定性 | 把数据离散度称价值偏好 |
| 决策 | 资源、路径、调度、控制 | 可行方案及目标值 | 忽略预测/权重不确定性 |
| 验证 | 对照、敏感性、误差传播 | 证据与适用域 | 只展示最优一次运行 |
| 解释 | 机制、特征贡献、建议 | 有边界的现实解释 | 把相关解释成因果 |

## 可复用组合模式

### 模式 1：数据清洗 → 可解释特征 → 基线 → 主模型

- **适用**：几乎所有有数据赛题。
- **核心价值**：把性能增益分成数据质量、特征和模型三部分。
- **必须验证**：预处理只在训练折拟合；分别做“原始+基线”“特征+基线”“特征+主模型”消融。
- **禁用信号**：清洗规则根据测试结果反复修改。

### 模式 2：PCA/因子 → 聚类 → 分群解释或分群建模

- **适用**：高相关多指标、群体异质性明确。
- **信息流**：去冗余表示 → 发现群体 → 对簇画像或分别预测。
- **风险**：主成分不可解释、聚类不稳定、分群只是装饰。
- **验证**：载荷稳定、多个 K/距离、Bootstrap 聚类稳定、分群模型相对全局模型有外测增益。

### 模式 3：客观/主观赋权 → TOPSIS/VIKOR → 排名稳健性

- **适用**：多指标评价且“重要性”与“信息量”来源不同。
- **信息流**：偏好/数据 → 权重 → 距离或折衷排序 → 权重情景。
- **风险**：重复指标、权重双重计数、组合系数无依据。
- **验证**：替换标准化、权重和排序法，报告名次区间而非只报唯一排名。

### 模式 4：预测 → 优化 → 情景/鲁棒性分析

- **适用**：需求、价格、风险等外生量先未知，后续需决策。
- **信息流**：历史与特征 → 预测分布 → 场景集/区间 → 决策模型。
- **风险**：点预测被当真值；预测最优不等于决策最优。
- **验证**：预测外测 + 决策回测；比较确定性、情景、鲁棒方案；报告错误传播。

### 模式 5：评价 → 优化

- **适用**：先定义效用/优先级，再配置资源。
- **信息流**：指标 → 可解释得分 → 目标/约束系数 → 资源方案。
- **风险**：评价权重和优化权重重复；得分单位无意义。
- **验证**：权重场景下方案稳定性、可行性和公平/效率权衡。

### 模式 6：聚类 → 分类

- **适用**：无标签探索群体，随后需对新样本快速归组。
- **风险**：把聚类标签当真实类别；分类器只复制不稳定簇。
- **验证**：聚类稳定、簇外部解释、分类概率校准、漂移监测。

### 模式 7：分类/风险评分 → 优化

- **适用**：预测事件概率或风险后分配有限资源。
- **风险**：分类阈值与决策成本脱节；概率未校准。
- **验证**：校准曲线、成本敏感阈值、端到端效用/后悔值。

### 模式 8：图构建 → 网络指标/社区 → 路径或资源决策

- **适用**：关系结构决定传播、连接或运输。
- **风险**：边定义含糊；中心性直接当影响力；静态图忽略时变。
- **验证**：边阈值敏感、网络扰动、与非网络基线对照、可行路径检查。

### 模式 9：机理模型 → 参数估计 → 残差学习

- **适用**：主机制明确，但存在系统性未建模误差。
- **信息流**：机理方程 → 参数/主预测 → 残差 → 轻量 ML 修正。
- **风险**：残差模型吸收数据泄漏；黑箱修正破坏守恒或边界。
- **验证**：纯机理、纯数据、混合三方对照；检查修正后物理约束。

### 模式 10：仿真 → 代理模型 → 优化

- **适用**：单次高保真仿真昂贵、需搜索大量策略。
- **信息流**：设计点 → 仿真响应 → 代理模型/不确定性 → 搜索 → 高保真复核。
- **风险**：在训练域外优化代理；代理误差导致伪最优。
- **验证**：空间填充采样、交叉验证、候选点高保真复算、序贯加点。

### 模式 11：Monte Carlo → 风险指标 → 鲁棒/随机优化

- **适用**：随机输入显著影响方案风险。
- **信息流**：分布/情景 → 输出样本 → VaR/CVaR/失效概率 → 决策。
- **风险**：尾部分布估计不足；情景数量与结论不收敛。
- **验证**：样本数收敛、分布替代、置信区间、样本外情景。

### 模式 12：候选模型集成

- **适用**：模型误差互补，且外测证明集成优于成员。
- **形式**：加权平均、Stacking、Bayesian model averaging。
- **风险**：在测试集调权；成员高度相关；集成牺牲解释却无增益。
- **验证**：嵌套/折外预测训练元模型、成员相关、集成增益和不确定性。

## 组合的验证设计

### 分层消融

对 `A → B → C` 至少比较：

1. 基线；
2. 只有 A；
3. A+B；
4. A+C（若逻辑允许）；
5. A+B+C。

每层报告主要指标、运行时间、稳定性和解释代价。若 B 不增加价值，删除 B，而不是把它留作“丰富论文”。

### 端到端验证

局部最优不保证全链最优。预测→优化链既要验证预测误差，也要验证最终成本、可行率、风险或后悔值。

### 接口扰动

对上游输出施加统计合理的扰动，观察下游结果：

- 参数在置信区间内变化；
- 排名权重在偏好区间内变化；
- 预测使用分位数/场景；
- 聚类用不同随机种子/距离；
- 图边权或阈值小幅变化。

如果微小接口扰动导致结论反转，必须降低结论强度或改用稳健方案。

## 反模式与拆除规则

| 反模式 | 症状 | 处理 |
|---|---|---|
| 名称串联 | “先 AHP，再熵权，再 PCA，再 TOPSIS”却无信息流 | 给每模块写独立职责；写不出就删 |
| 同义重复 | 多个模型都在做同一排序/降维 | 选一个主模型，其余做对照 |
| 装饰性聚类 | 聚类结果不影响任何子问 | 删除或明确探索性价值 |
| 预测后硬代入 | 下游只用一个点预测 | 传递区间/情景并做决策回测 |
| 黑箱套机理 | 残差学习破坏守恒/单调 | 约束修正或只学可解释项 |
| 测试集调参 | 组合权重、阈值看测试结果决定 | 嵌套验证/独立验证集 |
| 多算法“投票证明” | 多模型结论一致就称正确 | 检查共同偏差和数据来源 |
| 元启发式包围精确问题 | 可用 LP/MILP 却先上 GA/PSO | 精确法作主解或至少作小规模基准 |

## 案例库证据审计

现有模型共现与代表卡见 `corpus-analysis.md`；以下规则用于持续复核组合是否沿信息流成立。

- `[案例审计: MC-01]` 从案例卡统计真实组合链，按信息流而非模型名称归类。
- `[案例审计: MC-02]` 检查组合论文是否传播上游不确定性、是否做端到端验证；缺失须如实标注。
- `[案例审计: MC-03]` 识别本地论文中模型堆砌反例与成功精简方案，不因获奖身份免除批判性分析。
- `[案例审计: MC-04]` 为每个高频组合补充至少两个结构相似但题面不同的案例，验证迁移性。
- `[案例审计: MC-05]` 统计组合增益是否由消融或基线支持；无证据时只称“采用了组合”，不称“更优”。
