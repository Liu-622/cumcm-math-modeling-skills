# case-030：“互联网+”时代基于动态补贴的出租车资源优化配置

## 基本信息

- 【题目】“互联网+”时代基于动态补贴的出租车资源优化配置
- 【比赛/年份】CUMCM，2015
- 【论文文件/页数】`2015/B340…[1699784].pdf`，31页
- 【问题类型】综合评价、供需回归、政策响应仿真、补贴优化

## 决策链

- 【核心问题】宏观比较城市出租车供需；微观估计同一城市高峰/低谷、拥堵/非拥堵供求比；判断既有补贴；设计兼顾匹配与成本的动态补贴。
- 【数据特点】城市万人拥有量、满载率、里程利用率等指标量纲不同；深圳轨迹包含信息异常和经纬偏差；补贴通过拒单率、拼车率影响有效供给和需求，但缺少个体实验数据。
- 【问题拆解方式】指标隶属化并模糊综合评价→深圳数据清洗和空间图→分别回归供给/需求并计算供求比→用高斯函数刻画司机拒单、Logit刻画乘客拼车→修正有效供需形成打车难度系数→仿真现有方案→步长搜索纯匹配最优→把供求比0.8～1作为可接受区间降低成本→基础补贴上有限浮动形成动态规则。
- 【使用模型】模糊综合评价、多元回归、Gaussian/Logit行为响应、供求比和打车难度、等步长搜索、带可接受区间和浮动上限的动态补贴。
- 【模型选择理由】宏观指标含模糊等级，隶属度可合成城市评价；微观数据连续且需解释影响因素，采用多元回归；拒单/拼车是概率行为，故用概率曲线连接补贴与有效供需；设供求比区间而非强求1，直接回应“最匹配但太贵”的关键矛盾。
- 【考虑的替代方案】专家应以真实订单级Logit/因果响应估计函数，不应因“相关”直接指定高斯；宏观权重可用熵权/CRITIC与敏感性；政策可做预算约束的多目标规划或Pareto前沿。论文未系统比较这些方案。
- 【关键公式】宏观评价由隶属向量与权重合成；微观 `R=S/D`；拒单率和拼车率修正有效供给/需求，进一步定义打车难度；补贴搜索以 `R≈1` 或 `0.8<=R<=1` 为约束，实际补贴围绕基础补贴浮动不超过5元。见第5～22页。
- 【算法】清洗GPS/需求→计算宏观权重和城市分数→按时空场景回归供需→标定/设定两类响应函数→仿真无补贴、快的、滴滴→枚举司乘补贴组合→先选最匹配点，再在可接受区间选低成本基础点→按实时供需偏差动态调整。

## 可信度与创新

- 【模型验证方法】宏观三城和微观四场景结果方向对照；无补贴/两个平台方案比较打车难度与成功匹配次数；新方案再做同场景匹配仿真。未报告回归留出误差、函数参数置信区间和随机仿真分布。
- 【关键定量结果】三城宏观分数深圳0.1868、西安0.3046、拉萨0.7029；深圳四场景供求比0.7046、1.6037、0.6886、1.5813；无补贴/快的/滴滴难度0.2816/0.1885/0.2030；纯匹配最优为司机11.4元、乘客15.4元，低成本基础点为司机7.3元、乘客0元；新方案仿真匹配人数52→70，提升34.62%。
- 【创新点】宏微观双尺度评价；拒单和拼车作为补贴影响供需的中介；从“精确平衡”降为“可接受平衡区间”以换成本，再转为实时动态规则。
- 【论文结构亮点】问题三明确指出前一阶段优化的费用缺陷并加约束修正，创新来自现实矛盾而非换模型。
- 【主要局限】模糊权重由隶属赋值推得，主观性高；高斯拒单率的论证不足；回归可能混淆相关与因果；补贴仿真样本小且不含平台预算、跨区迁移和长期策略行为；34.62%是模型内结果。

## 迁移规则

- 【可迁移经验】先输出成本无约束上界，再给预算可行的次优方案；行为中介要逐项进入供需式；政策结论同时报告匹配、费用与公平性。
- 【不应该机械复制的部分】权重向量、供求比0.8～1、5元浮动、拒单基准0.3以及深圳单日参数均不可移植；仿真提升不能当现实效果承诺。
- 【相似题检索标签】宏观MCDA→微观回归→行为响应→情景仿真→成本约束优化。
- 【适用边界】有个体订单面板时应优先估计异质响应与因果效应；有跨区再平衡时需时空网络/多智能体模型，静态比率不足。
