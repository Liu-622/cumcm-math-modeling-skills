# case-059｜空气质量数据的校准

## 基本信息

- 【题目】空气质量数据的校准
- 【比赛】CUMCM
- 【年份】2019
- 【数据特点】六污染物时间序列含异常、重复和不同时间戳；气象变量与误差可能非线性相关。
- 【使用模型】三次样条插值、灰色关联、加权平均校准、RBF神经网络、逐步多元回归
- 【问题类型】探索分析、误差因素排序与多模型校准。
- 【证据边界】第 1 页摘要覆盖全部方法；第 2 页问题重述及第 28 页 RBF/回归实现抽样。

## 决策链

- 【核心问题】先描述六污染物分布和日内/长期变化；再删除异常重复、标准化并用三次样条对齐时戳，形成“自建—国控”误差；最后比较三种校准模型。
- 【问题拆解方式】质量控制 → 统计分布/可视化 → 样条对齐 → 误差与五气象变量灰关联 → 加权平均基线 → RBF预测误差 → 逐步回归解释关系。
- 【模型选择理由】样条为异步序列提供同一时间基准；灰关联用于逐污染物筛选关联因素；加权平均给简单基线，RBF处理非线性，逐步回归提供稀疏可解释公式。三者功能不同，不能只按复杂度排序。
- 【关键公式】误差校准结构为 \(y_{cal}=y_{self}-\hat e(x)\)，其中 \(\hat e\) 分别由加权基线、RBF或逐步回归估计。
- 【算法】对齐后以两站差作为监督目标；RBF从气象/污染特征预测误差并修正自建值；逐步回归通过变量进入/剔除形成公式；加权模型引入国控估计值。
- 【专家推断的替代方案】应用按时间切分训练/验证，防止样条邻近信息泄漏；比较 MAE/RMSE 和漂移时段误差，而不只给结果文件。

## 可信度与创新

- 【论文结构亮点】按子问题依赖顺序呈现：问题抽象、模型选择、算法求解、结果与验证，使前问输出自然进入后问。
- 【模型验证方法】摘要提供灰关联度大于0.9等结果，但未呈现三种校准的统一误差表；因此“RBF更优”不能从抽样证据推出。
- 【创新点】为同一误差任务并列可解释、线性和非线性路线，适合做模型选择实验；先预测误差再校正比直接预测浓度更贴合校准目标。
- 【主要局限】RBF超参数、训练划分及泛化误差未在抽样页明确；逐步回归受共线性/多重检验影响；样条可能平滑极端污染峰。

## 迁移规则

- 【可迁移经验】校准任务应把高质量基准差值作为标签，并用简单基线约束复杂模型的必要性；时间验证必须保持先后顺序。
- 【不应该机械复制的部分】关联度0.9、RBF结构、样条边界和变量筛选顺序不可复制。
