# case-074｜接触式轮廓测量仪的数据校正与工件轮廓重建

## 基本信息

- 【题目】接触式轮廓测量仪的数据校正与工件轮廓重建
- 【比赛】CUMCM
- 【年份】2020
- 【数据特点】轮廓由多段直线、圆和角构成；10次/9组测量存在刚性位姿偏差和局部噪声。
- 【使用模型】分段函数拟合、直线交点几何、多线段角度平均、特征点配准、多曲线融合
- 【问题类型】结构化几何拟合、刚性校准和重复测量融合。
- 【证据边界】第 1 页摘要、第 2 页重述及第 33 页程序抽样；题名依据摘要规范化。

## 决策链

- 【核心问题】问题一分段拟合水平工件并由交点/斜率算参数；问题二以水平轮廓为基准估倾角并旋转校正；问题三以10次倾角均值作标准再算工件2；问题四用最低点配准九组圆角曲线并融合成标准参数。
- 【问题拆解方式】轮廓分段 → 直线/曲线拟合 → 相邻函数交点 → 几何参数 → 多直线夹角平均 → 逆旋转 → 多次角度中心 → 特征点平移配准 → 九曲线合并拟合 → 擦除/修正异常轮廓。
- 【模型选择理由】工件有明确直线和圆角结构，分段参数模型比黑盒平滑更可解释；倾斜是刚体旋转，可由多对应直线夹角估计；重复测量必须先对齐，否则平均会模糊边缘。
- 【关键公式】刚性校准用 \(\mathbf p_i^*=R(-\theta)(\mathbf p_i-\mathbf t)\)，分段函数交点和斜率再用于几何参数计算。
- 【算法】分别拟合每段函数并求相邻交点；多条直线夹角取均值估旋转7.4779°；九曲线以最低点平移到同一特征点后合并拟合。
- 【专家推断的替代方案】最低点可能受噪声影响，可用ICP/鲁棒特征配准；角度平均应用圆统计/加权最小二乘并报告不确定度。

## 可信度与创新

- 【论文结构亮点】按子问题依赖顺序呈现：问题抽象、模型选择、算法求解、结果与验证，使前问输出自然进入后问。
- 【模型验证方法】将旋转校正后的参数与水平基准比较，差异处于论文认为的可接受范围；多直线平均用于降噪。摘要未给误差阈值和置信区间。
- 【创新点】将位姿校准与形状参数估计分开；九次曲线先做特征配准再融合，避免直接叠加。
- 【主要局限】10次均值被假定为标准值，可能保留系统偏差；最低点配准只校平移、未同时校旋转/尺度；分段点选择可能主观。

## 迁移规则

- 【可迁移经验】重复几何测量遵循“结构识别—刚性配准—多次融合—参数提取—基准对照”。
- 【不应该机械复制的部分】最低点特征、7.4779°、分段边界和均值标准假设不可复制。
