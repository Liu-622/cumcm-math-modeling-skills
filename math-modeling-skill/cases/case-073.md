# case-073｜基于Logistic守约率与多目标规划的中小微企业信贷决策

## 基本信息

- 【题目】基于Logistic守约率与多目标规划的中小微企业信贷决策
- 【比赛】CUMCM
- 【年份】2020
- 【数据特点】企业票据与信用标签；302家企业缺部分信用数据，事件情景需按行业/类型修改指标。
- 【使用模型】Logistic回归、守约率映射、多目标决策、相似规律补全、行业事件调整
- 【问题类型】可解释概率风险、贷款多目标规划和递进情景复用。
- 【证据边界】第 1 页摘要、第 2 页重述及第 38 页附录抽样；题名依据摘要规范化。

## 决策链

- 【核心问题】问题一用Logistic得到守约率p，并以额度x、利率r为变量平衡低风险与高利润；问题二从附件1学习缺失信用规律，使302家问题转回问题一；问题三按行业/类型疫情影响改指标并重算。
- 【问题拆解方式】数据/指标 → Logistic守约概率 → 0–1风险映射 → 贷款额度/利率/流失约束 → 无记录企业信誉与违约补全 → 嵌套原规划 → 行业事件方向/强度 → 指标修正 → 策略调整。
- 【模型选择理由】Logistic直接输出0–1概率且方向可解释，适合作规划风险输入；三问的决策变量和银行目标相同，复用模型减少结构漂移。
- 【关键公式】Logistic守约率 \(p_i=1/(1+e^{-\beta^Tx_i})\)，贷款目标在利润最大与 \(1-p_i\) 风险最小之间权衡。
- 【算法】对企业求p，风险随1-p增大；规划在总贷款额、利率区间、流失率等约束下同时优化风险和利润；问题二/三只更新企业属性与风险参数。
- 【专家推断的替代方案】“找相关规律”补信用必须交叉验证；多目标需明确权重/ε约束；概率需校准，特别是分布发生疫情漂移后。

## 可信度与创新

- 【论文结构亮点】按子问题依赖顺序呈现：问题抽象、模型选择、算法求解、结果与验证，使前问输出自然进入后问。
- 【模型验证方法】摘要未提供Logistic预测指标、校准或优化敏感性；优点主要是三问嵌套逻辑一致，证据强度低于 case-070/072。
- 【创新点】用统一守约率接口连接数据缺失补全、事件修正和贷款优化，软件结构清晰。
- 【主要局限】风险映射可能重复或扭曲p；缺失信用推断误差未传播到贷款结果；疫情只修改指标可能忽略关系结构变化。

## 迁移规则

- 【可迁移经验】递进赛题优先固定决策器接口，让后续问只更新风险估计和情景参数，并传播估计不确定性。
- 【不应该机械复制的部分】Logistic系数、流失函数、风险映射、疫情分类和规划权重不可复制。
