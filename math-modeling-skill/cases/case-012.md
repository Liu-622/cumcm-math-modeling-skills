# case-012｜嫦娥三号软着陆轨道设计与控制策略

## 基本信息

- 【题目】嫦娥三号软着陆轨道设计与控制策略
- 【比赛】CUMCM
- 【年份】2014
- 【数据特点】轨道端点和发动机参数已知，高程图用于避障；连续动力学、分阶段状态约束与多源扰动并存。
- 【使用模型】二体动力学、Pontryagin极大值原理、自适应模拟退火遗传算法、蒙特卡洛
- 【问题类型】带阶段切换的连续最优控制、轨迹仿真与不确定性分析。
- 【证据边界】证据包抽取第 1、2、23 页，并补充视觉复核第 3 页；以下“原文明示”均来自这些页，未覆盖公式细节须回源。

## 决策链

- 【核心问题】问题一由预定着陆点和轨道高度反求近、远月点及速度；问题二以上一步近月点状态为六阶段软着陆的初值，求最小燃耗控制；问题三对整条轨迹做误差、灵敏度和扰动落点分析。
- 【问题拆解方式】准备轨道二体模型 → 主减速最优制导 → 快速调整沿用制导律 → 近月面平动/转动分解与避障 → 扰动验证。该顺序保持状态量连续传递，而非把六段分别求解后拼接。
- 【模型选择理由】原文明示月面附近无大气、着陆仅数百秒，故忽略非球形引力和日月摄动，用二体模型保留主要机制；主减速以燃耗最小为目标且有状态方程和端点约束，采用哈密顿函数与 Pontryagin 极大值原理；近月面阶段用质心平动与绕质心转动分解降低维数。
- 【关键公式】状态方程与燃耗目标可概括为 \(\dot{s}=f(s,u),\ \min J=\int_0^{t_f}\dot m_f(s,u)\,dt\)，端点状态和推力范围构成约束；该式为专家标准化表达，具体变量按原文回源。
- 【算法】联立状态方程、共轭方程、边界条件求制导律；再以自适应模拟退火遗传算法搜索轨迹参数，作为独立数值路线。证据页 23 显示遗传交叉/变异后嵌入退火接受准则。
- 【专家推断的替代方案】可用直接配点法或多重打靶法替代间接极大值原理；若离散后形成可微非线性规划，优先比较 IPOPT 等确定性求解器，启发式只处理非凸初值与全局搜索。

## 可信度与创新

- 【论文结构亮点】按子问题依赖顺序呈现：问题抽象、模型选择、算法求解、结果与验证，使前问输出自然进入后问。
- 【模型验证方法】原文明示三层验证：理论估计被忽略摄动和月面形状的影响；用模拟退火遗传算法与极大值原理解交叉比较；用蒙特卡洛打靶观察质量、轨道高度和经纬度扰动造成的落点分布，并做单因素微扰灵敏度。
- 【创新点】把“间接最优控制解—全局启发式复核—随机扰动打靶”组成证据链；快速调整段复用主减速制导律，体现阶段之间的物理连续性。
- 【主要局限】忽略摄动与三维效应只在短时、近月环境成立；OCR 未覆盖完整参数辨识、收敛性及样本量，不能据卡片断言全局最优或概率可靠度。

## 迁移规则

- 【可迁移经验】航空航天、机器人着陆和车辆制动题可沿“机理状态方程—阶段端点约束—最优控制—独立数值复核—扰动传播”建模。
- 【不应该机械复制的部分】月球无大气、二体假设、六阶段边界、推力范围及退火/遗传参数均为题目专属。
