# case-070｜基于梯度提升决策树与多目标规划的中小微企业信贷决策

## 基本信息

- 【题目】基于梯度提升决策树与多目标规划的中小微企业信贷决策
- 【比赛】CUMCM
- 【年份】2020
- 【数据特点】123家有标记企业和302家无信贷记录企业；交易票据可构造经营指标，突发事件含行业与企业两层信号。
- 【使用模型】正则化梯度提升树、集成学习、非线性多目标规划、行业冲击分层
- 【问题类型】监督学习风险预测 → 企业评级 → 贷款组合优化 → 突发情景调整。
- 【证据边界】第 1 页摘要、第 2 页重述与第 54 页附录抽样；题名依据摘要规范化。

## 决策链

- 【核心问题】问题一从票据筛特征并预测违约概率，再最大化一年收益、最小化风险/流失；问题二把训练模型迁移到302家无记录企业并评级；问题三量化疫情行业/规模影响，改写风险和信贷策略。
- 【问题拆解方式】票据特征工程 → 正则化弱树 → 梯度迭代集成强分类器 → 违约概率 → 放贷0-1/额度/利率多目标规划 → 无标签企业信誉评级 → 行业/规模分层 → 股票宏观波动+72家同比微观变化 → 情景再优化。
- 【模型选择理由】树模型适合非线性、混合特征，正则项抑制树复杂度，梯度提升降低单树偏差；预测的个体违约概率是规划风险项，实现预测—决策衔接。
- 【关键公式】违约概率由提升树输出 \(p_i\)，贷款规划同时优化 \(\max\sum_i x_ir_i(1-p_i)\)、风险与客户流失。
- 【算法】训练集迭代拟合前轮残差并累加树；比较传统树和BP；规划同时考虑总额度、利率范围、是否放贷、违约和流失；疫情将企业分四类并调整信贷参数。
- 【专家推断的替代方案】准确率应补AUC、召回、概率校准和时间外验证；多目标应说明归一化/权重，最好给收益—风险前沿。

## 可信度与创新

- 【论文结构亮点】按子问题依赖顺序呈现：问题抽象、模型选择、算法求解、结果与验证，使前问输出自然进入后问。
- 【模型验证方法】报告集成树准确率96.75%，传统树83.87%、BP59.3%；问题三将收益从199.635万变为184.655万并解释社会效益。训练/测试切分未在抽样页明确。
- 【创新点】宏观行业股票与微观发票同比共同刻画事件冲击；将社会效益作为收益下降的现实解释，而非声称纯财务最优。
- 【主要局限】小样本下复杂集成易过拟合；股票价格不是行业经营损失的无偏代理；社会效益未进入正式目标函数量化。

## 迁移规则

- 【可迁移经验】预测—优化题必须让概率进入目标/约束并做概率校准；突发情景应同时看群体冲击和个体经营变化。
- 【不应该机械复制的部分】准确率、四类划分、行业股票代理、权重和贷款结果不可复制。
