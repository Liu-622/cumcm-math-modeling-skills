# case-055｜机场的出租车问题

## 基本信息

- 【题目】机场的出租车问题
- 【比赛】CUMCM
- 【年份】2019
- 【数据特点】人车流随时段变化，等待时间需由队列模拟估计；司机决策受队列长度、市区距离和单位时间收入共同影响。
- 【使用模型】0-1收益决策、队列模拟曲线拟合、泊位数优化、收益平衡阈值
- 【问题类型】个体二元决策、排队系统仿真、设施容量优化与公平规则设计。
- 【证据边界】第 1 页摘要、第 2 页背景/重述及第 28 页代码抽样。

## 决策链

- 【核心问题】问题一比较机场排队与空载返城的预期利润；问题二把机场分时段数据代入决策模型；问题三从管理者角度优化矩阵式上客泊位数；问题四让短途车优先但保持与正常司机收益均衡。
- 【问题拆解方式】两策略现金流/时间 → 0-1 选择 → 队列模拟估计等待 → 分时段决策 → 泊位数—车速—乘车效率优化 → 时间或里程短途票阈值。
- 【模型选择理由】策略互斥且目标是利润较大者，0-1变量足够；等待时间与车流关系难以解析，采用队列模拟后拟合；泊位增加提高并行服务却降低流速，必有容量权衡。
- 【关键公式】决策规则为比较 \(\Pi_{wait}\) 与 \(\Pi_{return}\)：\(Q=1\) 当等待预期利润更高，否则返城。
- 【算法】分别计算等待载客与空载返城收益，令决策变量选择较大值；仿真不同车流得到等待曲线；枚举/优化泊位数并取最接近最优的偶数；令短途司机与普通司机利润相等求时间/里程临界值。
- 【专家推断的替代方案】若到达和服务分布可估，可用排队网络；短途优先应再检查对普通队列等待分布而非仅均值的影响。

## 可信度与创新

- 【论文结构亮点】按子问题依赖顺序呈现：问题抽象、模型选择、算法求解、结果与验证，使前问输出自然进入后问。
- 【模型验证方法】原文用控制变量与目标变量偏导做依赖性分析，并称时段决策与机场实际基本吻合；这是合理性核对，不等于样本外预测。
- 【创新点】把司机个体最优、机场系统效率和短途公平放在同一收益口径下，形成多主体一致的规则。
- 【主要局限】均匀四时段可能掩盖突发航班；曲线拟合依赖仿真设定；“利润相等”不是唯一公平准则。

## 迁移规则

- 【可迁移经验】互斥策略先算完整机会成本；容量设计需同时描述并行服务收益和拥挤损失；优先权用可解释公平约束界定。
- 【不应该机械复制的部分】四个时段、二车道布局、泊位偶数约束与短途临界值均依赖机场。
