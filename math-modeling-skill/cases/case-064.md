# case-064｜基于一维热传递与混合启发式搜索的回焊炉优化

## 基本信息

- 【题目】基于一维热传递与混合启发式搜索的回焊炉优化
- 【比赛】CUMCM
- 【年份】2020
- 【数据特点】四个待估参数、分段炉温边界与一条实测曲线；决策空间经温度和速度步长离散。
- 【使用模型】一维热传导、牛顿冷却、有限差分、网格遍历、爬山算法、A星搜索
- 【问题类型】差分机理模型、组合参数遍历和约束工艺优化。
- 【证据边界】第 1 页摘要；题名依据摘要规范化，原首页被站点水印遮挡。

## 决策链

- 【核心问题】问题一联立炉内空气温度和焊接区域温度，拟合四参数；问题二遍历最大可行速度；问题三用爬山+A*最小化高温面积；问题四把面积和对称偏差平方线性加权。
- 【问题拆解方式】一维炉温边界 → 焊件热传导/牛顿冷却 → 初边值微分方程组 → 差分逐层求解 → 参数组合最小二乘遍历 → 速度循环 → 温度/速度混合搜索 → 加权双目标。
- 【模型选择理由】一维近似降低空间维度，有限差分使方程和工艺约束统一落到网格；参数数目较少可遍历；问题三离散空间下用爬山快速改进、A*引导候选搜索。
- 【关键公式】差分温度递推 \(T_{k+1}=\Phi(T_k,\theta,v)\)，双目标为高温面积与峰值两侧偏差平方的加权和。
- 【算法】枚举四参数并以实测曲线平方误差选优；对每个速度生成炉温曲线、筛制程可行；对温区/速度邻域做爬山并用 A*扩展候选，问题四用加权目标复用搜索框架。
- 【专家推断的替代方案】A*需有可采纳启发函数才有最优性保证；连续变量可用多起点非线性规划，搜索步长需报告收敛性。

## 可信度与创新

- 【论文结构亮点】按子问题依赖顺序呈现：问题抽象、模型选择、算法求解、结果与验证，使前问输出自然进入后问。
- 【模型验证方法】以实测炉温最小二乘拟合参数，并逐候选检查制程界限；摘要未给样本外误差与搜索重复性。
- 【创新点】将工艺制约同差分方程一起离散，允许同一仿真器服务参数估计和三类优化任务。
- 【主要局限】遍历/爬山结果依赖网格步长和初值；线性加权受量纲/权重影响；89页论文的完整实验未被三页OCR覆盖。

## 迁移规则

- 【可迁移经验】建立一个可复用机理仿真器，让辨识、约束检查和优化调用同一计算核心；离散搜索必须做步长收敛检查。
- 【不应该机械复制的部分】A*启发式、邻域结构、温度组合和速度结果不可复制。
