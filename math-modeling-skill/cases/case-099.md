# case-099｜基于成分数据的古代玻璃制品的成分分析与鉴别

## 基本信息

- 【题目】基于成分数据的古代玻璃制品的成分分析与鉴别
- 【比赛】CUMCM
- 【年份】2022
- 【题号/内容ID】C155 / 1820281
- 【论文文件】`2022/C155_2022高教社杯全国大学生数学建模竞赛C题论文展示(C155)_[1820281].pdf`
- 【证据范围】论文共41页；本卡以OCR抽取的第1、2、29页为直接证据，未覆盖页内容不作原文明示。
- 【问题类型】成分数据分析、假设检验、分类/聚类、敏感性分析

## 决策链

- 【核心问题】尊重化学成分定和约束，分析风化与文物属性关系、恢复风化前组成，建立玻璃类型/亚类判别，并比较两类玻璃的成分关联结构。
- 【数据特点】14项化学成分非负且总和约100%，含无效记录和零值；样本量小，类别、风化状态和纹饰/颜色均为混合型变量。
- 【问题依赖】
- 问题1清洗并把含量闭合到1，再做clr变换；用卡方/Yates检验风化关联，并回归预测风化前成分。
- 问题2用决策树分高钾/铅钡，再以R型特征聚类辅助Q型样本聚类划亚类。
- 问题3复用决策树判未知类型，并用Q型聚类交叉核验。
- 问题4对每类遍历母序列做灰色关联，比较关联分布。
- 【使用模型】中心化对数比变换、Pearson/Yates卡方检验、决策树、灰色关联分析
- 【模型选择理由】
- 成分数据的定和约束会产生伪相关，clr变换后再回归/分类是关键前处理。
- 当期望频数过小时用Yates校正，体现检验前提而非机械套卡方。
- 先R型聚类筛相关特征、再Q型聚类样本，降低冗余成分对距离的影响。
- 决策树提供可解释分类规则，聚类用作无监督交叉证据。
- 【考虑的替代方案】【专家推断】clr仍受零值处理影响，可比较ilr变换与多重零值替换；分类应使用分层/留一交叉验证，不能以训练集四指标均为1证明泛化。
- 【关键公式】clr变换 $z_j=\log(x_j/g(x))$ 消除闭合约束；卡方检验关联，决策树输出类型；灰色关联系数用于序列形态接近度但不等同统计相关或因果。
- 【算法】剔除无效记录→零值/总和处理并闭合→clr→按频数条件选Pearson或Yates→描述统计与风化回归→决策树分类→R型筛变量、Q型聚类→扰动重算→未知样本双模型核验→分类型灰色关联。

## 可信度与创新

- 【模型验证方法】分类精确率/召回率/准确率/F1；Q型聚类交叉检验；随机扰动敏感性；风化/未风化分层比较。
- 【关键定量结果】摘要报告决策树四项分类指标均为1，并称0.1–0.2范围随机扰动下聚类敏感性良好；这些可能基于小样本/训练数据，不能视为外部泛化保证。
- 【创新点】先处理单纯形几何再建模，避免成分数据最常见的伪相关；未知样本用监督分类与无监督聚类双路线核验。
- 【论文结构亮点】摘要按子问题明确呈现“输入/假设—模型—算法—结果—验证”，后问复用前问中间结果，逻辑链完整。
- 【主要局限】clr不能直接处理零值，替换规则影响结果；扰动方式若不保持总和为1会离开成分空间；灰色关联与统计相关含义不同。

## 迁移规则

- 【可迁移经验】凡比例总和固定的数据（配方、预算、群落丰度），优先使用log-ratio几何，再做回归、距离或分类。
- 【不应该机械复制的部分】不能对原始百分比直接算普通相关，也不能把训练精度1当完美模型；必须做成分空间内扰动和外部验证。
- 【相似题检索标签】成分数据分析、假设检验、分类/聚类、敏感性分析、中心化对数比变换、Pearson/Yates卡方检验、决策树、灰色关联分析
