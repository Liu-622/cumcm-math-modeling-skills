# case-071｜基于综合评价、RAROC与突发事件因子的信贷决策

## 基本信息

- 【题目】基于综合评价、RAROC与突发事件因子的信贷决策
- 【比赛】CUMCM
- 【年份】2020
- 【数据特点】11项指标覆盖实力、供求稳定、偿还与信誉；第二问标签缺失，第三问加入行业突发冲击。
- 【使用模型】熵权TOPSIS、RAROC、违约金字塔、Logit回归、BP神经网络、突发事件因子
- 【问题类型】客观赋权评价、分类/评级迁移和风险收益优化。
- 【证据边界】第 1 页摘要；题名依据摘要规范化。

## 决策链

- 【核心问题】问题一用11指标和熵权TOPSIS量化123家风险，再按RAROC/违约金字塔确定是否放贷、利率和额度；问题二用Logit预测违约、BP预测等级并复用风险与优化模型；问题三以三类突发因子调整信贷。
- 【问题拆解方式】票据预处理 → 四维11指标 → 熵权 → TOPSIS风险排序 → RAROC收益/风险规划 → Logit违约概率 → BP信誉等级 → 302家评分/优化 → 事件因子量化 → 策略前后比较。
- 【模型选择理由】熵权减少主观赋权、TOPSIS给多指标相对接近度；RAROC将收益与占用风险资本统一；Logit输出可解释概率，BP承担多类评级。模型功能不同但需检查信息重复。
- 【关键公式】TOPSIS贴近度 \(C_i=D_i^-/(D_i^++D_i^-)\) 用于风险排序，RAROC以风险调整收益/经济资本衡量放贷。
- 【算法】指标同向化/标准化后熵权加权，求正负理想距离；以风险评分和违约概率进入信贷约束/目标；疫情依据行业产值、利润等资料设置三种事件因子。
- 【专家推断的替代方案】熵权高离散不等于高风险重要性，需权重敏感；BP对小样本评级未必优于有序Logit/树模型；评分、概率和等级若同源应避免重复计权。

## 可信度与创新

- 【论文结构亮点】按子问题依赖顺序呈现：问题抽象、模型选择、算法求解、结果与验证，使前问输出自然进入后问。
- 【模型验证方法】Logit准确率84.6%；疫情策略与第二问比较并发现更偏高新技术行业。摘要未给TOPSIS权重敏感、BP验证和RAROC收益前沿。
- 【创新点】在原信贷框架内用事件因子做参数化情景调整，保持基线可比较；评价与风险调整收益明确分层。
- 【主要局限】多个模型可能重复使用同一信用信息；准确率不代表概率校准；事件因子来源与量纲融合需更严格。

## 迁移规则

- 【可迁移经验】评价分数负责相对排序，违约概率负责概率风险，RAROC负责决策，三者职责要清楚；事件冲击应作为参数/情景进入基线。
- 【不应该机械复制的部分】11指标、熵权、突发因子、评级网络和行业倾向不可复制。
