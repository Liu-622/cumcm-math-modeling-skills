# case-014｜嫦娥三号软着陆轨道设计与控制策略

## 基本信息

- 【题目】嫦娥三号软着陆轨道设计与控制策略
- 【比赛】CUMCM
- 【年份】2014
- 【数据特点】连续动力学和离散高程图并存；六阶段具有不同状态约束，主减速段水平位移占主导。
- 【使用模型】牛顿动力学、轨迹离散化、全局最优模型、平坦度评价
- 【问题类型】分阶段轨迹优化、图像型选址评价、灵敏度分析。
- 【证据边界】第 3 页摘要经视觉复核，第 28 页为 MATLAB 迭代代码片段。

## 决策链

- 【核心问题】先由着陆点所在经线平面和轨道几何求近远月点，再把这些状态作为六阶段控制的边界；粗、精避障从高程图选择安全区域；最后检验高度与推力变化。
- 【问题拆解方式】轨道几何/能量守恒 → 主减速轨迹离散 → 各阶段逐步迭代 → 高程图九分区平坦度选址 → 参数扰动误差。前一阶段终值是后一阶段初值。
- 【模型选择理由】牛顿第二定律直接连接推力、质量和轨迹；连续方程离散后可按时间步迭代，便于执行端点约束。粗精避障将相对高程差和标准差合成为平坦度，因为目标同时需要“低起伏”和“内部一致”。
- 【关键公式】离散递推结构为 \(s_{k+1}=s_k+\Delta t\,f(s_k,u_k)\)，优化目标为最小燃料消耗并满足各阶段终端状态。
- 【算法】在每步更新位置、速度、质量与推力方向；各阶段以燃耗最小和终端状态为约束。第 28 页代码显示对 1500–7500N 推力枚举/迭代并记录下落时间和末质量。
- 【专家推断的替代方案】地形选址可用坡度、粗糙度和可达性组成多指标评价；轨迹可用直接配点非线性规划统一求解，但须避免用统一模型抹掉各阶段不同物理机制。

## 可信度与创新

- 【论文结构亮点】按子问题依赖顺序呈现：问题抽象、模型选择、算法求解、结果与验证，使前问输出自然进入后问。
- 【定量结果】摘要给出近月点约 19.51°W、31.68°N、15km，远月点约 160.49°E、31.68°S、100km；速度约 1.692km/s 与 1.614km/s。仅作案例证据，不应移植到新题。
- 【模型验证方法】原文明示改变近月点高度和推力，分析水平位移、燃耗的方向关系；选主减速段做局部误差，并以各阶段时间相对误差作整体检查。
- 【创新点】在同一决策链中连接动力学轨迹与高程图平坦度，而非将避障当成脱离轨迹的静态选点。
- 【主要局限】九分区会掩盖局部危险；单因素灵敏度不能揭示参数交互；摘要未证明“全局最优”的数学充分性。

## 迁移规则

- 【可迁移经验】把连续系统离散为状态递推，再让安全评价结果进入控制阶段的终端约束；优先分析对总目标贡献最大的阶段。
- 【不应该机械复制的部分】九块划分、平坦度公式、端点数值和推力步长依赖本题分辨率与工程尺度。
